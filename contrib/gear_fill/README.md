# Level 99 gear stats, in chunks of ten items

This folder is a worksheet, not code to merge. It holds the level 99 equipment stats written on
the Vanadreams server, split into 230 files of ten items each so they can go to LandSandBoat a
little at a time, as its maintainers asked.

## What is in it

- 2,291 items: 1,640 that upstream shipped with no stat rows at all, and 651 whose existing rows
  did not match the item's own description.
- 20,426 rows added, 350 changed, 165 removed, across `sql/item_mods.sql`,
  `sql/item_mods_pet.sql` and `sql/item_latents.sql`.
- `NNN.sql`: ten items in item id order. Each item carries its name, id, whether it is a fill or
  a correction, its FFXIAH page, and its rows marked ADD, CHANGE (with the old row) or REMOVE.
- `INDEX.csv`: one line per item with its chunk, kind, row counts, and a status column to track
  which chunks have gone up as pull requests.

## Where the values came from

Every value is the item's in-game description text, read from its FFXIAH page. Pet lines went to
`item_mods_pet`, earrings that work in one ear became equipped-in-slot latents (latent 40).
Set bonuses, Unity Ranking ranges, aftermaths, additional effects and latent conditions that
LandSandBoat has no handler for were deliberately not written.

The change set is the difference between the three files at Vanadreams commit `d30241b45c^`
(upstream's tables as of 12 September 2026, base `d8ace89190`) and at `e66d5640f9`. It is
regenerated by `make_gear_chunks.py` in the Vanadreams workshop; do not edit the chunk files by hand.

## How a chunk becomes a pull request

The two scripts live on this branch, which is never the branch under test, so they are run by
piping them out of git from the fork's folder, on whatever branch is checked out:

1. `git show gear-fill-chunks:contrib/gear_fill/apply_gear_chunk.py | python - 001`
   makes branch `gear-chunk-001` off upstream `base`, puts the ten items' rows into the named
   files in item id order, stages them, runs LandSandBoat's own checks on the result, and marks
   the chunk applied in `INDEX.csv`.
2. Open each item's FFXIAH page and check every row against the description once more.
3. Write the commit. Then `git show gear-fill-chunks:contrib/port_check.py | python -` checks
   the commit message against their rules too.
4. `docker compose run --rm setup_database`, then look at the items in the client.
5. Push the branch and open the pull request against LandSandBoat/server `base`. One chunk, one
   pull request.
